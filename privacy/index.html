Privacy

Files never leave this device. The image tools read the files you pick and write new files for you to download. Graphics Bunch has no account system and no server that receives pictures.

The first time you remove a background or run the 4× upscale, the browser downloads a model. Codecs for AVIF and HEIC may also download. Those requests are for the model or the codec. They do not include the picture, the file name, or a licence key.

An analytics slot exists for Umami. It is off unless the site is built with both a script address and a website id. Umami, if you turn it on, is cookieless. Events may include the tool name and the plan name. They must not include file names, image bytes or licence keys.

The advert slot is empty. No advert script is loaded.

A Pro preview flag and any saved presets stay in this browser’s local storage. Clearing site data removes them. They are not a purchase. A member access code typed into the unlock field stays in that form. This version does not send it, store it, or turn Pro on.

Help

If a file fails, check the type and the 10 MB free limit, then try the sample on the tool page. For the WordPress plugin, use the support forum once the plugin is listed. This build does not send email. A Graphics Bunch support mailbox is not connected, and the domain in the site config is only a placeholder.
