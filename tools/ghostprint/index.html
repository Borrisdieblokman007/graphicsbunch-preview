    Questions

    Which tags are removed?

    JPEG APP1 segments that hold EXIF or XMP, and PNG eXIf, tEXt, iTXt and zTXt chunks. The ICC colour profile in a JPEG APP2 segment is kept. GPS latitude and longitude go with the EXIF segment.

    Does stripping upload the photo?

    No. The file is read in this browser. A download is the only new copy. Use this when you want GPS and camera serials gone before a listing upload.

    Will the JPEG look different?

    The entropy-coded picture is copied through. Only the metadata segments change, so the pixels are not run through a new JPEG save. A format that is not JPEG or PNG is re-encoded, and the report says so.
