How to use it

  1. 1Drop a photo. It stays on this device.
  2. 2Pick a square, portrait, landscape or story size. Unverified sizes are labelled.
  3. 3Choose a blur or a colour fill so nothing is cropped, then download the PNG.

Questions

Will the photo be cropped?

No. The whole photo is fitted inside the frame. Spare space is a blur of the photo or a flat colour.

Why do some sizes say unverified?

That platform’s help page did not publish the pixel size on the day this list was checked. The number is a placeholder so the file has a usable shape. It is not an official specification.
