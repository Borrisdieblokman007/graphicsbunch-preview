    Questions

    What does auto enhance actually do?

    It uses a grey-world white balance, stretches the tones when the picture has real contrast, and applies a light 3×3 sharpen. A flat colour is left alone so it does not turn black. The file is written as sRGB, which is what Etsy asks listing photos to use.

    Is this an AI enhancer?

    No. There is no generative model and no upscale. It is a colour and levels pass on this device, so a “no AI” edit stays private.

    Is Daylight free?

    Yes, including a batch of 10 files at 10 MB each. Pro only raises the batch cap. The same enhance is a paid step in the WordPress add-on, because that one runs on your server.

    Does the sRGB file replace a printer profile?

    No. Daylight writes sRGB, which listing sites expect. It does not replace a printer profile or a RIP. For a sublimation file, size the pixels in the resizer as well: a 10 inch side at 300 DPI needs 3,000 pixels.
