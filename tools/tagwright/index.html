    How to use it

    1. 1Type the product, colour and material. Empty fields are skipped.
    2. 2Process images for a lowercase filename and a one-row CSV. Words such as thumb, small and large are dropped.
    3. 3Preview Pro and tick alt text when you want a draft from the on-device model.

    Questions

    What filename pattern is used?

    Shopify’s product media guidance asks for a descriptive hyphenated name, and says to avoid names that end in thumb, small or large. This page builds product-colour-material-01.jpg from the fields you type.

    How does the alt text stay on this device?

    The Pro draft runs a MobileNetV2 image classifier in the browser. The model is Apache-2.0, lazy-loaded from this site only when you ask for alt text, and the photo is not sent with it. The label becomes a sentence such as “Product photo of kiln mug.”

    What is in the CSV?

    One header row, filename,alt, and one data row per image. You can paste that into a Shopify, WooCommerce or plugin import. The rename itself does not need the model.
