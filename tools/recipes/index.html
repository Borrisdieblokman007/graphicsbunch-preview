    How to use it

    1. 1Pick a recipe. The steps use the same size presets as the other tools.
    2. 2Drop the images. The batch runs on this device, one file at a time.
    3. 3Download the zip.

    What you get

    Recipes run a batch workflow and download one zip. Listing photo sets, pins, print files and the social kit use the shared size list. Files stay on this device.

    Questions

    Do the photos leave this device?

    No. A recipe reads the files you drop and writes new files for the zip. There is no upload.

    What can I run without Pro?

    Built-in recipes run on 3 files at a time, with the long edge capped at 2,048 pixels. Pro preview lifts that cap to about 200 files, keeps full resolution, and unlocks custom recipes plus import and export.

    Can I change a recipe?

    Preview Pro, duplicate a built-in or start a new chain, then save it in this browser. Export writes a small JSON file you can import on another device.
