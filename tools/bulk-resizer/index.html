    Questions

    Will a small photo be enlarged to the preset?

    Yes. Standard resize uses the browser scaler so the file matches the pixel size. It can look soft. AI 4× is a separate Pro control and uses a different model. Enlarging raises the pixel count. It cannot invent detail that was not in the photo.

    What size should a sublimation file be?

    At 300 DPI a 10 inch side needs 3,000 pixels. Choose PNG if you want to keep transparency from the background remover. The pixel count is the size of the file, not a promise of how a particular printer will look.

    Which fit should I use for a product?

    Contain keeps the whole product and pads the rest. Cover fills the frame and crops the edges. Amazon main images should use contain on pure white.

    Is AVIF included?

    Yes. WebP, AVIF, JPEG and PNG are on the free tier. AVIF is not held back for Pro.
