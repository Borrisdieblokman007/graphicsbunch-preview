Tips

  • A Facebook Page cover is 851 × 315. A computer shows a left-aligned 16:9. A phone shows a left-aligned 2.4:1, and the profile photo covers about 40 pixels of the bottom.
  • YouTube publishes a safe area of 1,235 × 338 on the minimum file. This tool scales that box onto 2,560 × 1,440. YouTube does not say the box is centred.

Questions

What does the coloured band mean?

A solid band is a size the help page published. A dashed band is calculated from a published ratio, or it is unverified. The downloaded PNG leaves the guides off.

Why is there no cover for every platform?

Only platforms that publish a cover, plus an unverified header where the help page did not return a pixel size, are listed. A missing cover is a decision, not a guessed canvas.

Where does a Facebook cover get cropped?

The file is 851 × 315. A computer shows a left-aligned 16:9. A phone shows a left-aligned 2.4:1, and the profile photo covers about 40 pixels at the bottom. Turn on safe zones to see those bands. They stay off the PNG.

Is the YouTube safe box centred?

YouTube publishes 1,235 × 338 at the minimum 2,048 × 1,152 file. This tool scales that box onto 2,560 × 1,440 and places it in the centre. YouTube does not say the safe area is centred, so that placement is marked unverified.
